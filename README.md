# Ridimensiona immagini

Ridimensiona e comprimi immagini direttamente nel browser, senza caricarle su un server.

## Come si usa

1. Apri la pagina e seleziona le immagini oppure scegli una cartella.
2. Imposta il peso massimo desiderato per ogni file: il valore predefinito è **600 KB**.
3. Scegli il metodo di riduzione e premi **Ridimensiona immagini**.
4. Scarica i risultati singolarmente oppure raccoglili in un unico file ZIP.

Le immagini già entro il limite vengono mantenute senza modifiche. Gli originali non vengono sovrascritti: i risultati sono file separati.

## Formati supportati

- **JPEG**
- **PNG**
- **WebP**
- **BMP** (il risultato viene salvato in PNG)

I file TIFF non sono supportati. La compressione e la codifica dipendono dalle capacità del browser; se il limite impostato non può essere raggiunto, il file viene segnalato.

## Privacy

L'elaborazione avviene localmente nel browser. Le immagini non vengono caricate su un server. Per creare il download ZIP viene caricata da una CDN la libreria JSZip; le fotografie restano sul dispositivo.
